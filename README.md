# deploy-agent

Скилл для развёртывания OpenClaw-агентов на чистых серверах «под ключ».

## Что делает

Автоматизирует полный цикл: от подключения по SSH до запуска готового Telegram-бота с агентами, моделями и скиллами.

## Основные фичи

- **Защита от потери данных** — атомарная запись SECRETS.md + MEMORY.md, контрольные точки
- **Верификация токенов** — проверка длины и валидности Telegram-токена перед использованием
- **Трёхуровневая валидация скиллов** — файл → symlink → после рестарта, с автооткатом при ошибках
- **Динамический каталог скиллов** — собирается с локального `~/.openclaw/skills/`, никаких захардкоженных списков
- **Обязательные скиллы** (без спроса): agent-doctor, agent-forge, ru-text
- **Дополнительные скиллы** — только после явного выбора пользователем
- **Единый механизм установки** — scp с локального сервера, без git clone и ClawHub
